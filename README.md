# Anderson, o Resende — 18 anos

Uma homenagem interativa, cinematográfica e emocionante celebrando o aniversário de 18 anos de Anderson (Resende) e quase sete anos de uma amizade sincera que começou em uma partida de Free Fire no Réveillon de 2019.

## Tecnologias e Arquitetura

- **React 18**: Componentes modulares, gerenciamento de estado declarativo (`App`, `BirthdayCanvas`, `ChapterView`, `EnvelopeModal`, `SquadDiagram`, `Transitions`, `HeartHeader`).
- **TypeScript**: Tipagem estrita de capítulos, partículas, física de balões, confetes e animações.
- **Vite**: Build moderno e ultra-rápido configurado para a porta 3000.
- **HTML5 Canvas 2D**:
  - Supernova e intro cósmica com partículas formando o coração paramétrico (`HPT`)
  - Simulação física de balões com cordas flexíveis e iluminação radial
  - Fitas ondulatórias procedurais
  - Sistema de confetes com rotação 3D simulada
  - Partículas douradas formando o número "18"
  - Bolo de aniversário animado com chamas de vela dinâmicas
- **Tailwind CSS**: Cores temáticas (`#174F88`, `#318DE0`, `#79C5FF`, `#B9E0FF`, `#EAF5FF`, `#F5FAFF`) e tipografia fluida com *Nunito* e *Caveat*.

## Capítulos da Homenagem

1. **O Começo de Tudo** (Madrugada de 31.12.2019 no Free Fire, Francielle e os primeiros xingamentos)
2. **Sete Anos de Uma Coisa que Virou Natural** (A rotina de uma amizade verdadeira)
3. **O Nosso Nível de Maturidade** (As conversas sem filtro e piadas internas)
4. **O Que Tu Representa Para Mim** (A liberdade de ser quem é e o valor da família escolhida)
5. **A Vez em que a Distância Fez Falta** (Superação e reconexão)
6. **Uma Confissão que Não Cabe Numa Conversa Aleatória** (O segredo do envelope e sinceridade sem máscaras)
7. **Uma Coisa que Eu Preciso Agradecer** (Gratidão genuína pelo companheirismo)
8. **Ainda Temos Uma Coisa Pendente** (A promessa do encontro pessoal)
9. **Dezoito Anos, Seu Desgraçado** (A celebração dos 18 anos com bolo e confetes)
10. **A Última Mensagem** (O encerramento e o legado da amizade)

## Execução

```bash
npm install
npm run dev
```
O servidor de desenvolvimento inicializará em `http://0.0.0.0:3000`.
